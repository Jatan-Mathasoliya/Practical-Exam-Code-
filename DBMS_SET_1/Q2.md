# Question 2

Write SQL queries for the following operations on the `MenuItem` table:

---

## (a) Insert three menu items in one query

```sql
INSERT INTO MenuItem (item_id, item_name, price, category)
VALUES
	(1, 'Burger', 120, 'Fast Food'),
	(2, 'Pizza', 200, 'Fast Food'),
	(3, 'Coffee', 80, 'Beverage');
```

---

## (b) Update the price of any one item

```sql
UPDATE MenuItem
SET price = 100
WHERE item_id = 3;
```

---

## (c) Delete one item using `item_id`

```sql
DELETE FROM MenuItem
WHERE item_id = 2;
```

---

## (d) Find the average price of all items

```sql
SELECT AVG(price) AS AveragePrice
FROM MenuItem;
```

---

## (e) Find the sum of all prices

```sql
SELECT SUM(price) AS TotalPrice
FROM MenuItem;
```
